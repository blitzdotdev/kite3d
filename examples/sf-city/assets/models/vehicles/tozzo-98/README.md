# Tozzo '98 sedan

Model: **Tozzo '98 - Low poly model**, by **Daniel Zhabotinsky** (https://sketchfab.com/DanielZhabotinsky).

Licensed **CC BY 4.0**, https://creativecommons.org/licenses/by/4.0/ . Attribution, license and original source URL are embedded in the supplied GLB and retained in the adapted glTF.

Original source: https://sketchfab.com/3d-models/tozzo-98-low-poly-model-d43bb748da364af2b3f0a9348365f0fb . The original page returned HTTP 403 in this environment and was not retried. The model file was obtained beforehand from the public `grey sedan.glb` file in https://github.com/Abhirupdatta9/ar-cars-test . No authentication or access-control workaround was used.

Modifications: externalized textures/buffer; normalized length to 4.5 m and ground contact; rotated to face local -X; flattened the static part hierarchy while retaining named editable parts. Paint variants are inferred. This is a substitute sedan, not the actual photographed vehicle and not an endorsement by the author.

Run `node build.mjs` to adapt the included original `source.glb` offline. Only `f.gltf`, `geometry.bin` and its referenced textures are runtime resources.
